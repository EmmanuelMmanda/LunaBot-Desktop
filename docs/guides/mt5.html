Connect MT5

Select the right terminal and connect the exact broker account you intend to use.

Have these details ready#

You need an MT5 Demo account and its exact broker server and login. LunaBot can prepare a separate terminal, or you can select an existing installation. Enter the password only in the app or MT5, never in a support message. Choose Demo first when learning LunaBot.

The broker server is a server name, not the broker’s website address. Use the exact value supplied with the account.

Prepare MetaTrader 5

  1. Choose MT5 Demo and enter an account name.
  2. For an isolated workspace, review the MetaQuotes terms and select Install for this account. Approve the official Windows prompt if requested.
  3. Keep the same setup open while LunaBot checks the dedicated folder. A delayed installer does not mean you should launch another copy.
  4. After verification, use the opened MT5 window to create or sign in to your Demo account. Use the small Open MT5 action if it did not appear.
  5. Alternatively, use Browse or Detect to select an existing terminal. Do not share it between simultaneously connected accounts.

LunaBot checks the actual executable and data directory. Dedicated workspaces use portable mode; an account is not ready merely because an installer exited. Use Continue setup from Operations to return to the same job.

Choose how to sign in

  1. Select the saved MT5 sign-in choice only when the selected terminal is already signed in with saved access. LunaBot checks that identity; it does not silently switch accounts.
  2. For a newly prepared dedicated terminal, choose the trading-password option if you need LunaBot to sign in. Check the exact broker server and account number.
  3. Select Connect account once. Keep MT5 available while the account is verified.

LunaBot does not store the entered password. MT5 saved access is a separate terminal setting. Netting versus hedging is an account property, not an authentication method.

Wait for the account check#

LunaBot checks the login, server, account type, currency and trading permissions, then reads the broker’s records. Allow extra time on a slower computer.

Connection setup does not place a trade. Before monitoring, confirm the displayed account and wait for a recent successful update.

Reconnect and startup options#

If the connection drops, reconnect the selected account and allow positions and orders to refresh. Avoid repeatedly clicking Start or launching more terminals while the connection is still starting.

In Settings → Trading mode, you can choose whether LunaBot reconnects at startup and whether monitoring resumes after a verified reconnect. Automatic mode can then submit eligible entries, so review both settings together.

If connection fails#

Account or server mismatch
Check the exact account number, server and terminal installation. Demo and Live can use different servers.
Password rejected
Check the exact server, login and trading password inside that same terminal. A vendor authentication rejection does not identify which one is wrong. If attaching without a password, verify that MT5 saved access is available. Do not reinstall or create duplicate terminals just to retry authentication.
Terminal takes too long
Read the connection progress and error. Check that MT5 is installed and the network can reach the broker before retrying.
Connected but no orders
Check the account’s trading permissions, LunaBot’s mode, monitoring and strategy state. A connection alone does not enable trading.
