Connect MT5

Select the right terminal and connect the exact broker account you intend to use.

Have these details ready#

You need an installed MT5 terminal, an existing broker account, its exact server name, account number and trading password. Choose Demo first when learning LunaBot.

The broker server is a server name, not the broker’s website address. Use the exact value supplied with the account.

Choose the terminal#

  1. Select MT5 Demo or the intended account type.
  2. Enter an Account name that you will recognise.
  3. Use Detect to find installed terminals, or Browse to select the intended terminal64.exe.
  4. Select Continue.

LunaBot starts or reattaches to the selected terminal in hidden mode. Selecting a different installation can mean a different saved login or server.

Enter account access#

  1. Check the account name.
  2. Enter the Broker server. Demo may suggest MetaQuotes-Demo; replace it if your broker uses another server.
  3. Enter the Account number.
  4. Enter the Trading password. Leave it blank only if the selected terminal already has saved access.
  5. Select Connect hidden MT5 once and follow the progress.

The password is used for this connection and is not stored by LunaBot. A saved terminal login is a separate MT5 setting.

The account-access step. The suggested Demo server must match your broker.

Wait for the account check#

LunaBot checks the login, server, account type, currency and trading permissions, then reads the broker’s records. Allow extra time on a slower computer.

Connection setup does not place a trade. Before monitoring, confirm the displayed account and wait for a recent successful update.

Reconnect and startup options#

If the connection drops, reconnect the selected account and allow positions and orders to refresh. Avoid repeatedly clicking Start or launching more terminals while the connection is still starting.

In Settings → Trading mode, you can choose whether LunaBot reconnects at startup and whether monitoring resumes after a verified reconnect. Automatic mode can then submit eligible entries, so review both settings together.

If connection fails#

Account or server mismatch
Check the exact account number, server and terminal installation. Demo and Live can use different servers.
Password rejected
Confirm the trading password with the broker. Do not paste it into a support report.
Terminal takes too long
Read the connection progress and error. Check that MT5 is installed and the network can reach the broker before retrying.
Connected but no orders
Check the account’s trading permissions, LunaBot’s mode, monitoring and strategy state. A connection alone does not enable trading.
