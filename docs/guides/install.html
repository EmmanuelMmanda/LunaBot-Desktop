Install & first launch

Download LunaBot, choose your appearance and set up your first account.

Download and install#

Use the latest Windows release. Download the Windows installer and SHA256SUMS.txt from the same release.

  1. Confirm that the installer name and version match the release you opened.
  2. Compare its SHA-256 with SHA256SUMS.txt. In PowerShell, run Get-FileHash .\LunaBot_[version]_x64-setup.exe -Algorithm SHA256.
  3. Open the installer. Windows may show SmartScreen before setup begins; use the next section to review it safely.

Prefer an archive? Download the ZIP alternative, choose Extract all, then run the included setup EXE. The ZIP contains the same installer; it is not a portable version.

If Windows SmartScreen appears#

Windows can show Windows protected your PC when an installer does not yet have a widely trusted reputation. Do not disable SmartScreen.

The wording and layout can vary by Windows version. Continue only with the installer downloaded from the official LunaBot release.

  1. Choose More info.This reveals the app name, publisher and the second action.
  2. Check the file.The name and SHA-256 must match the official LunaBot release. Stop if they do not.
  3. Choose Run anyway.Use this only after the file check passes. The LunaBot setup window opens next.
Do you see a different warning?

Choose Don’t run, keep the installer, and contact LunaBot support with a screenshot. Never send account passwords or activation keys.

Follow the welcome tour#

The tour introduces Overview, Trade Desk, market charts, strategy controls and connected apps. Use Continue and Back to move through it.

On Your profile, enter a display name and choose your display timezone. Select Save & continue. Charts, reports and activity use that timezone; a strategy’s session filter has its own timezone.

The welcome screen. Choose Light, Dark or System before continuing.

Choose an account#

Paper simulator
Practice with local simulated prices and funds. No broker account is required.
MT5 Demo
Connect a Demo account you already created with your broker. LunaBot does not create the broker account for you.
MT5 Live
Connect a real-money account. Live trading has separate activation and account permissions.

Choose your environment and select Set up account. For Demo, continue with Connect MT5.

Set up Paper practice#

  1. Choose Paper simulator.
  2. Give the account a short name and enter the starting balance.
  3. Review the details and select Create simulator.
  4. Open Overview and check that the account is labelled PAPER.

Paper trades help you learn the controls. Their prices and results are simulated.

Before your first session#

  • Confirm the account name and type in the top bar.
  • Choose a trading mode in Settings. Observe only is useful while learning the screens.
  • Review risk limits and the markets you want to follow.
  • For strategy trading, add and review a strategy before starting monitoring.

Go to Overview for the daily checks, or set up a strategy.
