Settings, updates & help

Personalise LunaBot and manage account rules, app access and updates.

Trading mode and startup#

In Trading mode, choose Observe only, Review & approve or Automatic and save. Startup behaviour is configured separately: reconnect the account, resume monitoring after reconnect, and whether pausing stops the managed MT5 terminal.

Automatic monitoring can submit eligible entries after startup. Read the confirmation before saving that combination.

Risk limits and markets#

Risk limits contains account limits for trade risk and the other supported account controls. Review units carefully, especially percentages, lots and broker points.

Markets controls the watched symbols. Changes are account-specific; check which account is selected before saving.

Profile, appearance and the tray#

Use the profile menu to edit your display name and timezone. Choose the supported Light, Dark or System appearance.

Review desktop preferences for minimising or closing to the tray and whether Exit from the tray is allowed while the app is locked. Closing a window to the tray can leave LunaBot running.

Quick Monitor gives a small account view. Use its full-workstation action when you need the chart, order ticket or detailed settings.

App lock and PIN#

Use Authentication to manage the local app lock. If you lose the PIN, start recovery from the lock screen and send the displayed App code to support.

PIN recovery is separate from licence renewal. Never share the PIN, trading password or full activation token.

Activation#

Open About → Licence details to see the device code, activation state and expiry.

After expiry, new exposure is blocked. You can still view records and use permitted cancellation, closure and protection that does not increase exposure. Activation does not automatically resume trading.

For renewal or device replacement, contact support with the device code. Re-downloading an existing licence does not extend its expiry.

Check for updates#

  1. Open About → Check for updates.
  2. Read the available version and release notes.
  3. Download the verified installer when offered.
  4. Review open positions and local management before installation.
  5. Reopen LunaBot, reconnect and refresh broker records before resuming monitoring.

Updates come from the public LunaBot-Desktop GitHub releases. Installation requires your action. The current release is unsigned.

Get help#

Check Setup status for connection and setup problems, and Audit trail for recorded actions. Include the installed version and steps to reproduce when reporting an issue.

Email luneya17@gmail.com for private support, or use GitHub issues with a sanitised screenshot.
