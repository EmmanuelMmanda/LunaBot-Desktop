Set up strategies

Choose a strategy, review its settings and decide when it may trade.

In LunaBotStrategies → Add strategy

Choose or import a strategy#

Open Strategies and choose Add strategy, or open Library to select an available recipe. A library item is a starting definition; it is not automatically an active deployment.

Import JSON accepts supported strategy definitions. Imported strategies are saved disabled and inherit the account mode. Review them before activation.

Work through the five steps#

  1. Market: select the exact broker symbol and timeframe.
  2. Parameters: review each setting for the selected strategy type. Names and available fields depend on that type.
  3. Filters: add only the filters you intend to use.
  4. Risk & execution: review the strategy’s risk allocation, spread limit, minimum reward/risk and execution mode.
  5. Review: check the full definition, name it clearly and save.

Saving registers the strategy’s market for the account. Check the saved strategy’s enabled state separately.

The Parameters step in the five-step strategy builder. Values shown are an example.

Choose filters deliberately#

Session window
Choose start/end times, weekdays and the timezone for that trading window.
Quote freshness / spread
Reject entries when a quote is stale or the spread exceeds your limit.
Cooldown / frequency
Limit how often the strategy version can create new entries.
News blackout
Block entries around selected economic releases during monitoring. This calendar filter is not applied to historical backtest replay.

No filter blocks means no additional filter rules; it does not mean the strategy will trade every candle. Its signal rules and account checks still apply.

Activate and monitor#

  1. Open the saved strategy’s details.
  2. Confirm its market, timeframe, version and risk settings.
  3. Activate it when ready.
  4. Confirm the account’s mode and start monitoring.
  5. Read its latest activity before assuming it should have traded.

Inherit uses the account mode. A strategy cannot use its settings to bypass account permissions or risk limits.

Edit, test or archive#

Open a strategy and select Edit to return to the builder. Review all five steps before saving. Keep the version in mind when comparing research and trading results.

Run a backtest to inspect historical behaviour. Forward Test shows observations collected over actual elapsed time.

Archiving disables the strategy and preserves its history. Restoring an archived strategy leaves it disabled until you review and activate it.

If it does not trade#

Check the latest activity message first. Then check monitoring, enabled state, account mode, the exact market, enough closed candles, quote freshness, session filters and risk limits. A valid “no signal” result needs no repair.
