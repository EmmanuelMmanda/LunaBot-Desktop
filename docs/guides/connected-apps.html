Connected apps

Connect an assistant to the accounts and actions you choose.

Choose your client#

  1. Open Settings → Connected apps.
  2. Select Connect assistant.
  3. Choose Codex, Claude Desktop, Claude Code or Other.
  4. Give the connection a recognisable name and choose its access duration.

The selected assistant must support MCP. Its installation and sign-in are separate from installing LunaBot.

Select accounts and permissions#

Tick the accounts this assistant may use. Start with Account records if you only want it to read the account.

Read & research
Read balances and trades, run research or review saved records.
Strategy & Scouts
Create proposals, disabled strategy drafts or change permitted Scout handling.
Account controls
Change specific risk, mode or monitoring settings when granted.
Broker operations
Request supported orders or position actions. Manual preview and manual submission are separate permissions.

Group selection changes the permissions in that group. Review the individual ticks before continuing.

Client selection and account permissions. This is a setup draft with no external client connected.

Configure the client#

Select Create and continue, then follow the client setup instructions. The app can help detect supported hosts and prepare their local configuration. Use manual configuration when the guided option is unavailable.

Keep existing unrelated client settings. If the client requires a restart to load its MCP configuration, restart it before verification.

Verify a real connection#

  1. Run the local connection test.
  2. Open the selected assistant and request a permitted read, such as the account’s current status.
  3. Return to Connected apps and inspect the session state and latest request.

A configured entry or local test does not mean the assistant has sent a request. Check the actual client session before assuming it is connected.

Manage or revoke access#

Use Manage to change the connection’s accounts or permissions. Saving rotates access, so the client must reconnect. The row’s additional actions include setup, test, access rotation and revocation.

Review Scout policy separately. Research-only records ideas; approval-required prepares eligible proposals; Automatic handling also needs the required account mode and execution permissions.

Revoking a connection stops its access. It does not close existing broker positions.

If the assistant cannot connect#

Check that the selected client is installed, its configuration loaded, LunaBot is available, the grant has not expired and the account is shared. After access rotation, update or reload the client configuration as instructed.

Never send the connection credential, broker password or licence token in a public issue.
