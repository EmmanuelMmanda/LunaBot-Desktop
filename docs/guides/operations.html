Operations

See what each account is doing, what needs attention and how much of your computer LunaBot is using.

Choose an account#

Open Settings → Operations. Select an account tab to see its connection, monitoring and worker details. This page is global: changing the account selected elsewhere in LunaBot does not silently switch the Operations tab. Setup jobs also appear here so you can return to work that is still running.

Paper practice does not need an MT5 terminal. Each managed Demo or Live account uses its own terminal installation and data directory; an installation already assigned to another account cannot be shared for concurrent operation.

Understand the status#

Connected means LunaBot verified the selected broker login and synchronised account records. It does not mean monitoring is on or that new trades are allowed. Those are shown separately.

Check the last sync time and quote freshness. A recent heartbeat alone is not proof that prices are updating. A closed market may still have a valid account connection while quotes are unavailable or stale.

During setup, Operations shows the current stage, elapsed time, last update and whether LunaBot is waiting for you. A percentage appears only when the work has measurable progress, such as a download with a known size. Installer steps without measurable progress are described plainly rather than assigned a guessed percentage.

Computer resources#

The host summary reports LunaBot-managed CPU and memory separately from Windows-wide available memory and disk space. Memory is shown as an amount, for example 2,000 MB managed · 16.0 GB total RAM. LunaBot's shared engine is counted once, not once per account.

Account details can show the worker and its verified MT5 terminal separately. If Windows does not provide a measurement, LunaBot shows Unavailable rather than treating missing data as zero. Resource readings are sampled; they are not broker response time.

Account actions#

Use the selected account's controls to open its workspace, continue setup, reconnect, pause new entries or stop that account's terminal. A reconnect verifies identity and reconciles positions, orders and any uncertain broker request before monitoring can resume.

Stopping or disconnecting LunaBot does not close broker positions or pending orders. It can stop LunaBot's local management of them. Read the confirmation and reconcile the account before restarting monitoring. Actions for one account should not restart another account's terminal.

Setup in progress#

You can continue setup in the background and return from its Operations entry. Leaving the page does not start a second attempt. If the official MT5 installer is open, LunaBot may be waiting for you to finish it; cancelling LunaBot's setup does not automatically close or uninstall that separate installer.

After setup, check the broker name, masked account number, environment, connection, quote freshness and existing positions/orders. A successfully connected account starts with monitoring off unless you deliberately enable it later.
