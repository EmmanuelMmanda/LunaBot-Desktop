# LunaBot 0.2.2

Add strategy now opens the strategy builder directly, starting with Market. Browse existing recipes through the separate Library tab.

This release also includes the latest manual-order styling, compact Settings layout and Quick Monitor workstation-opening improvements.

## Download and install

Download the Windows x64 setup EXE, or extract the installer ZIP and run the same EXE. Close LunaBot before installing. Your existing account data, strategies and settings remain in place.

After installation, open LunaBot and check the account and monitoring state before continuing. Installation interrupts local management; broker-held trades are not closed by installing an update.

The release includes a manifest and SHA-256 checksums. The installer is **unsigned**; checksums verify file integrity, not publisher identity. Do not disable Windows security protections.

Desktop version: **0.2.2**. The bundled engine retains its independent **0.2.0-rc.2** label and protocol 1.
