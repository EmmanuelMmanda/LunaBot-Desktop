About this download

The 0.2.5 installer is unsigned. A checksum verifies file integrity, not publisher identity. Do not disable Windows security protections. The release includes the Windows x64 installer, ZIP alternative, manifest and SHA-256 checksums.

Close LunaBot before upgrading. Installation interrupts local monitoring and management, but does not close broker-held trades. After reopening, verify the account connection and monitoring state before continuing.

Monitoring and strategy feedback

Monitoring distinguishes a connected terminal from fresh market prices. Stale or missing prices show a warning, and new entries remain blocked. Strategy details report the latest attempt, including stale candles, warm-up and entry checks; data failures retry without waiting for the next full candle interval.

Verification and limits

Release 0.2.5 includes focused feed/activation checks and isolated Paper browser checks. The unchanged bundled engine previously passed 529 tests and a 25-command packaged smoke check. Four unrelated broader UI assertions remained unresolved in the release evidence; this is not certification of every feature or Live trading.

Broker feed availability and market hours are outside LunaBot's control. No trading performance or profitability is guaranteed. Read the full 0.2.5 release notes →

Update without losing your place

  1. Back up the local database and retain the installer for your current version.
  2. Review open positions and orders before closing LunaBot. Broker-held trades remain open; local management is interrupted while the app is stopped.
  3. Use only the official release assets. The ZIP alternative contains the installer; it is not a portable app.
  4. After an update, verify account identity, reconcile broker records and check price freshness before resuming monitoring.

Do not open a database upgraded by a new version in an older engine. For recovery, restore a compatible backup into a separate location and reconcile before reconnecting. Keep the current data intact until recovery is verified.
